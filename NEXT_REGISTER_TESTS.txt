NEXT CONTROLLED BACKUP TESTS FOR v0.3+ FEATURES
================================================

Use one harmless test product and create a fresh backup after EACH isolated action.
Do not combine actions in one backup.

1. ADD ONE NEW PLU
- Record barcode, description, price, group, status/tax profile, stock setting, and any CRV link.
- Back up immediately after adding it.

2. DELETE THAT SAME PLU
- Back up immediately after deleting it.

3. MOVE ONE EXISTING TEST PRODUCT TO A DIFFERENT EXISTING GROUP
- Change only the group link.
- Back up immediately.
- Then move it back and create another backup.

4. CHANGE ONE PRODUCT TO A DIFFERENT EXISTING STATUS/TAX PROFILE
- Do not edit the shared status group itself.
- Record the old and new profile numbers/names.
- Back up immediately.
- Restore it to the original profile and create another backup.

5. CRV TEST
- Choose one test beverage whose deposit behavior is already known.
- Change only the CRV/deposit assignment using the same method the register normally uses.
- Back up immediately.
- Return it to the original setup and create another backup.

6. GROUP CREATE/RENAME TEST
- Create or rename one unused test group only.
- Back up immediately.

These comparisons are required because add/delete, tax/status, and CRV operations may update multiple .PGM files and indexes—not only PLU.pgm.
